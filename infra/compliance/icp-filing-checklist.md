# ICP 备案检查清单（中国大陆上线）

适用对象：AI 视频生成平台（Web + API + APP），使用阿里云 OSS 存储、
阿里云 CDN 加速国内访问。**未取得备案号前，国内 CDN 域名无法启用，
80/443 端口会被云厂商拦截。**

> 备案要求以工信部及各省通信管理局最新规则为准；本清单用于内部自查，
> 不替代接入商（阿里云）备案专员的审核意见。

## 0. 一句话流程

```
域名实名认证 → 购买境内服务器（≥3 个月）→ 阿里云备案系统提交 →
管局审核（7–20 个工作日）→ 取得备案号 → 公安联网备案（30 日内）→
开通 80/443 与 CDN → 页面展示备案号
```

## 1. 备案前硬性条件

- [ ] 域名已完成**实名认证**，且实名主体与备案主体一致（个人/企业）。
- [ ] 域名注册商为境内持牌机构，或已完成域名转入/实名信息同步。
- [ ] 域名后缀在工信部许可列表内（`.com` `.cn` `.net` `.com.cn` 等；
      `.io` `.ai` 等部分后缀不支持备案）。
- [ ] 已购买**中国大陆境内**服务器/ECS/ACK 节点，且剩余时长 ≥ 3 个月
      （阿里云要求；包年包月实例需 ≥ 3 个月）。
- [ ] 服务器已分配**公网 IP**（阿里云备案需绑定实例）。
- [ ] 主体证件在有效期内：企业营业执照 / 个人身份证。
- [ ] 非法人办理时，已准备**授权委托书**（加盖公章）及经办人身份证。
- [ ] 网站负责人手机号、邮箱可接收核验短信/邮件，且未在其他备案中占用。

## 2. 主体与网站信息

### 2.1 主体信息

| 项目 | 企业 | 个人 |
| --- | --- | --- |
| 证件 | 营业执照 | 身份证 |
| 负责人 | 法定代表人 or 授权经办人 | 本人 |
| 联系方式 | 座机 + 手机 + 邮箱 | 手机 + 邮箱 |
| 住所 | 营业执照注册地址 | 身份证地址或常住地址 |

- [ ] 主体名称、证件号与证件完全一致（含括号、英文大小写）。
- [ ] 主体已在阿里云完成**实名认证**，且与备案主体一致。
- [ ] 同一主体下已有备案的，确认未超过各省域名数量限制
      （部分省份企业 ≤ 5 个网站/主体，个人更严格）。

### 2.2 网站信息

- [ ] 网站名称：不得包含「中国」「国家」「政府」「新闻」「医疗」等
      需前置审批或易被驳回的词；建议使用品牌名（如「XX AI 视频创作」）。
- [ ] 网站服务内容：选择「其他」或「科技/信息服务」，不得选择新闻、
      出版、教育、医疗、金融等需前置审批类别。
- [ ] 网站首页地址：`https://app.example.com`（备案时通常填域名，
      不要带路径）。
- [ ] 网站语言：中文简体（面向国内用户）。
- [ ] 备案域名：`app.example.com`、`api.example.com`、`cdn.example.com`
      均应纳入备案（同一主体同一网站下可添加多个域名；CDN 域名必须
      已备案才能添加加速域名）。
- [ ] 域名解析：备案审核期间不要将未备案域名解析到境内服务器。

### 2.3 前置审批（AI 视频平台重点）

按实际业务判断，命中即需先取得对应许可证，否则管局直接驳回：

- [ ] **信息网络传播视听节目许可证**（《信息网络传播视听节目许可证》）
      —— 平台自行提供影视/视听节目内容点播、直播、聚合时通常需要；
      仅提供工具生成并存储用户作品，需与属地广电部门确认边界。
- [ ] **网络文化经营许可证**（文网文）—— 涉及网络表演、音乐、动漫、
      艺术品等经营性文化活动时。
- [ ] **广播电视节目制作经营许可证** —— 自制节目内容时。
- [ ] **ICP 经营许可证（增值电信业务经营许可证）** —— 向用户收费、
      提供付费会员/算力套餐等经营性互联网信息服务时，需在完成
      **ICP 备案**后另行申请（备案 ≠ 经营许可）。
- [ ] **算法备案 / 生成式人工智能服务备案** —— 面向公众提供生成式
      AI 服务，按《生成式人工智能服务管理暂行办法》履行备案/登记，
      并在页面公示算法备案号。
- [ ] **深度合成服务备案** —— 涉及 AI 换脸、视频合成等深度合成功能时，
      按《互联网信息服务深度合成管理规定》办理。

> 建议：上线前把「是否收费」「是否提供公开内容社区」「是否涉及
> 深度合成」三个问题书面确认，再决定许可证组合。

## 3. 阿里云备案操作步骤

- [ ] 登录阿里云 ICP 代备案管理系统（需实名账号）。
- [ ] 选择「首次备案」/「新增网站」/「新增接入」。
- [ ] 填写主体信息 → 填写网站信息 → 上传证件照片（原件彩色扫描，
      四角完整、无反光）。
- [ ] 完成**人脸核验**（阿里云 App 或小程序）。
- [ ] 提交初审（阿里云 1–2 个工作日）。
- [ ] 初审通过后，按短信提示完成**工信部短信核验**（24 小时内，
      超时退回）。
- [ ] 管局审核（各省 7–20 个工作日，期间保持电话畅通）。
- [ ] 审核通过后下载**备案号**与备案证书。

### 常见驳回原因

| 原因 | 处理 |
| --- | --- |
| 网站名称含敏感/前置审批词 | 改用品牌名，删除「新闻/中国/医疗」等 |
| 证件照片模糊、边缘裁切 | 重新拍摄原件，四角留白 |
| 主体负责人与证件不一致 | 更新阿里云实名信息或提供授权书 |
| 网站内容与备案类别不符 | 调整服务内容描述，必要时先办前置审批 |
| 域名实名信息未同步 | 等待 3–5 个工作日或联系注册商同步 |
| 手机号/邮箱重复占用 | 更换负责人联系方式 |
| 服务器剩余时长不足 3 个月 | 续费后再提交 |

## 4. 备案通过后（上线前）

- [ ] 在网站首页底部展示备案号，并链接到 `https://beian.miit.gov.cn/`。
      示例：`京ICP备XXXXXXXX号-1`。
- [ ] 若有 APP/小程序，完成**APP 备案**（工信部移动互联网应用程序备案），
      在应用市场提审时填写备案号。
- [ ] 取得备案号后，在阿里云 CDN 控制台添加加速域名
      `cdn.example.com`（前提：域名已备案且主体一致）。
- [ ] 配置 CDN 回源 OSS、HTTPS 证书、URL 鉴权 A、缓存规则
      （见 [`../aliyun/README.md`](../aliyun/README.md)）。
- [ ] 在 nginx/Ingress 放行 80/443；确认阿里云安全组已放行。
- [ ] 完成**公安联网备案**：自网站上线之日起 30 日内，登录
      「全国互联网安全管理服务平台」提交，取得公安备案号，并在
      网站底部展示（部分省份要求与 ICP 备案号并列）。
- [ ] 若使用收费服务，申请 ICP 经营许可证，并在页面公示许可证编号。
- [ ] 生成式 AI / 深度合成功能上线前完成算法备案，公示备案号。

## 5. 变更与维护

- [ ] 主体信息变更（名称、证件、法人）→ 30 日内办理**备案变更**。
- [ ] 新增域名/网站 → 办理**新增网站**或**新增域名**，不要直接解析上线。
- [ ] 更换服务器/接入商 → 办理**新增接入**或**接入备案**。
- [ ] 网站停止服务 → 办理**注销备案**，避免被列入异常名单。
- [ ] 每年配合管局/接入商**备案信息核验**（电话、短信、邮件），
      失联可能导致备案被注销。
- [ ] 备案号被注销后，国内 CDN 与 80/443 会立即失效，需重新备案。

## 6. 平台侧落地检查（代码/配置）

- [ ] `CDN_DOMAIN`、`NEXT_PUBLIC_CDN_URL` 使用**已备案**域名。
- [ ] OSS Bucket 保持私有，播放链接全部走 CDN 鉴权 URL
      （`CDN_AUTH_KEY` + `CDN_URL_TTL_SECONDS`）。
- [ ] 页脚组件展示 ICP 备案号 + 公安备案号 + 算法备案号（如适用），
      链接到官方查询页。
- [ ] 用户生成内容（UGC）具备审核与举报入口，满足内容安全要求。
- [ ] 隐私政策、用户协议、未成年人保护提示可公开访问。
- [ ] 数据存储在中国境内（OSS `cn-shanghai`），不出境传输个人信息。

## 7. 时间线参考

| 阶段 | 耗时 | 负责方 |
| --- | --- | --- |
| 域名实名 + 服务器购买 | 1–3 天 | 运维 |
| 阿里云初审 | 1–2 个工作日 | 阿里云 |
| 工信部短信核验 | 24 小时内 | 主体负责人 |
| 管局审核 | 7–20 个工作日 | 通信管理局 |
| 公安联网备案 | 上线后 30 日内 | 运维/法务 |
| CDN 域名启用 | 备案通过后 1 天 | 运维 |
| ICP 经营许可证（如需） | 20–60 个工作日 | 法务 |
| 生成式 AI 备案（如需） | 1–3 个月 | 法务/算法 |
